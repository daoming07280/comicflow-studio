# 第二版：镜头抖动与音色修订

根据用户反馈修复风格样片抖动，并按「自然沉稳的男声，适合长合集」调整配音。

## 当前结果

- 新版成片：`outputs/0ff570538797/final.mp4`，45.5 秒，1024×768，24 fps。
- 声音：`zh-CN-YunyangNeural`（云扬），标准语速 `+0%`。这是更换实际声音模型，没有对旧音频降调伪装。
- 画面：固定光学中心，以小数坐标做双三次插值缩放，保留 2.4% 的轻微推近，并缓慢起步、收尾。
- 工作台、后台和命令行的新任务默认都使用云扬、标准语速；旧任务的配置和视频保留。
- 工作台增加「试听当前声音」，可以按所选音色和语速生成短试听，播放成功的结果会缓存。切换音色或语速后需要重新试听。

## 抖动原因与处理

原先的 FFmpeg zoompan 镜头会将裁切窗口及位置取整，并受到色度采样对齐影响。即使缩放参数连续增加，实际画面仍会周期性发生像素级偏移。原先的两倍放大处理不足以消除这种跳动。

现在逐帧计算带小数的反向仿射变换，先生成 RGB 画面，再交给编码器。镜头中心不再经过整数裁切位置计算。新渲染器有独立缓存版本，旧的抖动片段不会被新任务复用。

## 验证结果

| 验证 | 修复前 | 修复后 |
|---|---:|---:|
| 5 秒中心标记测试：最大相邻帧位移 | 0.9932 px | 0.0267 px |
| 5 秒中心标记测试：中心位置全程波动 | 1.0439 px | 0.0756 px |
| 实际样片第一镜头：最大相邻帧中心位移 | 1.4156 px | 0.0085 px |
| 实际样片第一镜头：中心位置全程波动 | 1.0093 px | 0.0421 px |

实际画面测量屏蔽底部字幕，通过特征点光流与相似变换估计光学中心；其数值包含跟踪误差。它检测无意的中心跳动，正常推近造成的边缘移动仍然保留。

- `motion-fix-audit.json`：5 秒中心标记的编码后比较。
- `reference-motion-audit.json`：实际样片第一镜头的逐帧比较。
- `voice-motion-tests.xml`：**37 项测试全部通过**，新增运动稳定性、编码管道停止、音频缓存帧率、沉稳音色默认值及试听接口测试。
- 新版成片的音频与视频时长均为 **45.500000 秒**；全片解码、字幕边界和画面覆盖检查通过。

逐帧生成采用流式输入，不把每一帧写到磁盘；编码阻塞时仍可停止任务。另修复了音频缓存键缺少帧率的问题，避免修改帧率后错误复用旧时长音频。

## 使用

刷新或重开工作台即可看见新版样片。以后新建任务时，默认已是云扬和标准语速。也可以选择其他声音，先点击「试听当前声音」，再制作整部合集。

旧版风格样片仍在 `outputs/7e229bcabac1/final.mp4`；修复后的版本使用新的任务编号，不覆盖旧片。
