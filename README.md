## 立即使用

1. 双击根目录的 **启动漫画放映室.cmd**。当前电脑的依赖已经安装，不需要重新安装。
2. 默认打开「搜索漫画」，输入书名，点开作品、选择章节，然后点击「下载选中章节并导入」。完整下载后，素材和合集名称会自动填好。已有漫画可切换到「本地导入」。
3. 选择「自动讲读」，保留默认 Edge 中文声音，点击「开始自动制作」。默认需要联网配音，但不需要密钥；识别在本机运行。
4. 完成后直接播放、下载 MP4，或打开「逐段审片」查看每格图、文字、声音和时间轴。

无需素材也能试跑：点击「先跑一个完整流程」，再开始制作。内置图片是明确标注的虚构技术测试图。

关闭浏览器不会停止后台。需要停止后台或重新加载视觉服务配置时，双击 **停止漫画放映室.cmd**，随后重新启动。处理中关闭后台会保留已完成步骤，再次打开后可继续。

## 推荐输入方式

```text
漫画名称/
  第01章/
    001.jpg
    002.jpg
  第02章/
    001.webp
```

也支持把 `第01章.cbz`、`第02章.cbz` 放进同一文件夹。文件扩展名为 JPG/JPEG/PNG/WebP/BMP/TIF/TIFF。每次最多 20000 个文件、解压后总计 4 GB；更大内容按卷制作。

中文和英文 OCR 是默认能力。**韩语原版不能直接当作中文讲读输入**；请用中文译本，或连接支持韩语图片理解的视觉服务。没有文字的画面会短暂停留；整部无可识别文字时仍可导出无声视频，但会在审片说明中明确记录。

## 自备文案与配音

先用讲读模式处理，审片页会给出 `p00001` 等分镜编号。图片和排序不变时编号稳定。在漫画根目录加入 `narration.json` 后，选择自备模式新建任务：

```json
{
  "scenes": [
    {"panel_ids": ["p00001"], "text": "这里是第一段解说。"},
    {
      "panel_ids": ["p00002", "p00003"],
      "text": "这里是第二段解说。",
      "audio": "voices/02.wav"
    }
  ]
}
```

必须按顺序覆盖全部分镜，每格恰好一次。`audio` 可省略；省略时生成配音，提供时使用根目录以内的音频。支持 WAV、MP3、M4A、FLAC。多格共用一段时均分时长，不进行语义层面的自动对齐。

## 可选 AI 剧情解说

根目录建立 `vision.env`，填写你已有的视觉服务信息：

```dotenv
COMICFLOW_VISION_BASE_URL=http://127.0.0.1:1234/v1
COMICFLOW_VISION_MODEL=你的视觉模型名称
COMICFLOW_VISION_API_KEY=服务要求时填写
```

服务须兼容 `POST /chat/completions`，支持 `image_url` 输入和 JSON 对象输出。密钥为空时不会发送 Authorization 头，便于本地模型使用。关闭后台、重新启动后选择 AI 模式才会调用服务并发送所选画面。

每批最多 5 格：结合之前的解说生成草稿 → 再对照图片复核 → 检查每格顺序和覆盖 → 缓存结果。错误会重试最多 3 次；持续失败则停止并报告，不冒充成功，不自动退回其他文案模式。没有外部小说、百科或未来剧情输入。

## 命令行与公开链接

```powershell
# 自动讲读
.venv\Scripts\comicflow.exe run "D:\漫画\我的漫画" --title "我的漫画合集"

# 已有文案，按参考案例的 4:3 形式制作
.venv\Scripts\comicflow.exe run "examples\reference_recut" --mode manual --preset classic

# 离线中文配音
.venv\Scripts\comicflow.exe run "examples\starter" --tts windows --preset preview

# 恢复指定任务
.venv\Scripts\comicflow.exe resume 任务编号

# 下载给定公开链接，下载后导入目标目录
.venv\Scripts\comicflow.exe download "https://网站/漫画章节" --destination "data\downloads\漫画名" --range "1-100"
```

下载器不会加载你全局的 gallery-dl 配置或浏览器登录资料。默认请求前 500 个媒体项目，`--range` 是媒体编号范围，不是保证的漫画章节范围。请选择具体章节链接并核对下载页数。付费、登录、站点不支持或访问失败会在日志中体现。源码研究与官方参考见 [docs/RESEARCH.md](docs/RESEARCH.md)。

## 自审与实际限制

成片自审通过只代表视频技术指标符合要求，不代表文案绝无识别错误或剧情理解绝对正确。默认 OCR 没有识别人物、区分对白归属和改写故事的能力；低置信度结果在审片说明中记录。字幕以分段真实时长按字数分配，不是逐字强制对齐。没有明显留白的长图可能切到跨格内容，原图与坐标保留供核对。

输出中的 `plan.json` 是文案；`timeline.json` 包含每段和每格的起止时间、来源与坐标；`audit.json` 给出技术检查；`narration.flac` 是无背景音乐的无损配音。

长合集会保留较多中间文件以便恢复。最终 MP4 导出后，即使删除缓存也不影响 MP4 使用，但会失去原任务的恢复和逐格审片能力。

## 开发与重新安装

当前环境已安装完毕。换电脑时需 Python 3.11+、uv、FFmpeg/ffprobe，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\install.ps1
.venv\Scripts\python.exe -m pytest -q
```

测试含实际 FFmpeg 渲染及音频采样数回归；默认测试不调用在线配音或真实视觉服务。长视频压力测试独立运行：`.venv\Scripts\python.exe scripts\stress_test.py`。
